# MoodText

**Анализ настроения текста (Sentiment Analysis)** с помощью DistilBERT.

Проект определяет эмоциональную окраску текста по 5-уровневой шкале:
- **Very Negative**
- **Negative**
- **Neutral**
- **Positive**
- **Very Positive**

---

## Возможности

- Быстрый анализ настроения русского и английского текста
- Веб-интерфейс на Flask
- Лёгкая модель DistilBERT (6 слоёв)
- Поддержка длинных текстов (до 512 токенов)

---

> **Модель** хранится отдельно (не коммитится в репозиторий из-за размера).

---

Запусти приложение - python app.py
