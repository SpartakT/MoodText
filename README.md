# Multilingual Sentiment Analysis

Веб-приложение для анализа тональности текста на разных языках. В основе используется модель multilingual-sentiment-analysis из библиотеки Transformers.

Приложение автоматически определяет язык текста и оценивает его эмоциональную окраску. В результате возвращается наиболее вероятная категория настроения, уровень уверенности модели и полный список предсказаний.

Поддерживаются тексты на разных языках, включая английский, русский и другие.

## Установка

Создайте виртуальное окружение и установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:5000
```

## Как работает

Пользователь отправляет текст через веб-интерфейс или API.

Приложение определяет язык текста с помощью langdetect, после чего передает текст в модель анализа тональности.

В ответ возвращаются:

* определенный язык текста
* наиболее вероятная эмоциональная оценка
* уровень уверенности модели
* список всех полученных оценок
